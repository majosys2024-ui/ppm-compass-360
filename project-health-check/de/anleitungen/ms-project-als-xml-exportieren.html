MS Project als XML oder Excel exportieren

Der kostenlose Projekt-Health-Check liest Microsoft-Project-Pläne als XML oder Excel-Export. Das XML-Format enthält auch die Baseline, damit sehen Sie Meilenstein-Verschiebungen schon mit einer Datei.

XML (empfohlen)

  1. Falls Sie mit Basisplänen arbeiten: zuerst einen setzen (Projekt → Basisplan festlegen).
  2. Datei → Speichern unter, Dateityp XML-Format (*.xml) wählen.
  3. Den Projekt-Health-Check öffnen und die .xml-Datei in Schritt 1 ablegen.

Excel

Datei → Exportieren → Projekt als Datei speichern → Microsoft-Excel-Arbeitsmappe und die Spalten Name, Anfang, Ende, % abgeschlossen, Ressourcennamen, Meilenstein und Geplantes Ende mitnehmen.

.mpp-Dateien können im Browser nicht gelesen werden. Menünamen können je nach Version abweichen.

Was das Tool verwendet

  • Sammelvorgänge werden zu Gruppen; in Project markierte Meilensteine werden automatisch erkannt.
  • Das geplante Ende (Basisplan 0) dient als Baseline. Ohne Basisplan ist der früheste geladene Export die Baseline.
  • Ressourcennamen werden zu Verantwortlichen, % abgeschlossen zum Status.
