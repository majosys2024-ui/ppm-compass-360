Free project plan template for Excel (with phases and milestones)

A simple, free project plan template for Excel: one row per task, five phases, milestones marked, owners and dates. It works on its own in Excel, and it loads straight into the free Project Health Check for delivery metrics and a milestone timeline.

The file has 16 example tasks, including 6 milestones from kickoff to project close, and a “How to use” sheet.

How to use it

  1. Replace the example tasks with your own and keep the Task IDs stable.
  2. Update status, dates and completed dates as the project moves.
  3. Save a dated copy once a month, for example Project-plan-2026-11-01.xlsx.
  4. Load two dated copies into the Project Health Check: you get adherence to plan, overdue work, a Project Health Score and how each milestone moved.
