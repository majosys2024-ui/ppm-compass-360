Privacy Policy for Project Health Check

Project Health Check is a browser-only tool. Your files and project data never leave your computer.

1. 100% Client-Side Processing (Zero Data Upload)

When you drop or select a file (Microsoft Planner export, Jira CSV, MS Project XML, Excel, or CSV) or paste spreadsheet cells, all parsing, calculations, metric generation, and timeline rendering are executed entirely inside your web browser using local JavaScript.

No project data, task names, assignees, dates, or file contents are ever uploaded to any server, database, or cloud storage.

2. Browser Local Storage

The tool uses browser localStorage exclusively for:

  • Remembering whether you have unlocked the extended portfolio view (dhc-unlocked).
  • Remembering your confirmed custom column mappings (such as header names, date formats, and status labels) so you don't have to re-map them every time.

No task data, file names, or plan titles are ever written to persistent storage.

3. Email Form (Extended Portfolio Unlock)

If you choose to unlock the extended view (up to 5 plans and 12 dates), you can optionally submit the unlock form. The only information transmitted is:

  • Your email address
  • Your tool selection (e.g. Planner, Jira, MS Project)
  • Project count and team size range
  • Microsoft 365 usage indication
  • Your consent and optional monthly reminder preference

This form submission is transmitted securely over encrypted HTTPS directly to our form service processor (Web3Forms) to deliver your confirmation. No project data, file names, or task contents are ever attached to this form.

4. Strict Content Security Policy (No Trackers)

The application runs under a strict Content Security Policy (default-src 'self'). It loads zero advertising pixels, zero third-party analytics trackers, and zero external surveillance cookies.

5. Contact

If you have any questions about this privacy pledge or our data governance principles, please contact us at privacy@ppmcompass.com.
