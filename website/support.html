Step-by-Step Instructions

How to Deploy the Solution Package (.sppkg)

PPM Compass 360 is packaged as a standard Microsoft SharePoint Framework client-side solution: ppm-compass-360.sppkg. Deployment requires SharePoint Administrator permissions and takes under 5 minutes.

1

Open Your SharePoint Tenant App Catalog

Navigate to your Microsoft 365 SharePoint admin center (https://[tenant]-admin.sharepoint.com), click More features, and select Apps (Manage apps) to enter the App Catalog.

2

Upload & Enable the Solution

Drag and drop ppm-compass-360.sppkg into the Apps for SharePoint library. In the trust prompt dialog, check "Enable this app and add it to all sites" (or leave unchecked to add it only to specific site collections), then click Enable app.

3

Navigate to Your PMO / Project Site

Go to the modern SharePoint communication or team site where you want your project managers and executive stakeholders to collaborate.

4

Add the Web Part to Any Modern Page

Click Edit on your page, click the + icon to insert a web part, search for "PPM Compass 360", select full-width or single-column layout, and click Republish.

✓

Automatic List Initialization (Zero Configuration)

On first launch by a Site Owner, PPM Compass 360 automatically provisions the required SharePoint lists (PPM_Projects, PPM_Milestones, PPM_Risks, PPM_ChangeRequests, PPM_Team) with proper indexed columns, views, and schemas. You are immediately ready to create projects!

Frequently Asked Support Questions

What SharePoint permissions are required for the first installation?

To upload the package to the App Catalog, you need SharePoint Administrator or Global Administrator rights in Microsoft 365. To add the web part to a site and allow it to initialize the underlying lists, you need Site Owner / Full Control permissions on that specific site collection.

How do Project Leaders and team members get access?

All users belong exclusively to the site's Visitors group (Zero Member Access Architecture). To maximize governance and safeguard your SharePoint environment, no regular user ever requires SharePoint "Members" or "Contribute" permissions to the site collection.

The built-in Admin Settings page enables Site Owners to automatically break list permission inheritance on the PPM lists to grant write permissions to Visitors based on their granular role in each project or portfolio (e.g. designated Project Leader in PPM_Team). In addition, the Admin Settings page allows administrators to hide the underlying SharePoint lists from Site Contents and Quick Launch, ensuring users interact only through the governed web part and cannot bypass the UI or tamper with records directly.

How does the 30-Day Evaluation / Trial version work?

The trial version is 100% fully featured with no artificial project caps, no feature disabling, and no watermarks. You can test all 7 drawer tabs, the 3×3 risk & issue matrix, the dedicated My Portfolio cockpit, and report exports with your live team. When you purchase an annual license, your existing SharePoint lists and project data carry over seamlessly without needing reinstallation.

Can we export data if we ever decide to uninstall?

Yes! Because all data is stored directly in standard SharePoint Online lists, you retain 100% ownership at all times. You can export the entire portfolio to Excel directly through the web part or native SharePoint list export anytime.
