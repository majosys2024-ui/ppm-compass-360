v1.3.0 Latest Release
28 September 2026 - Production Build (SPFx 1.3.0.0)

Package Version 1.3.0.0

Projects can now be linked directly to your organization's strategy with visual coverage, owner assessments, and single-primary budget rollups.

What's New

  • 🎯 Strategy (optional module): A new Strategy screen shows your strategies, objectives and initiatives, who owns them, how the linked projects are doing, and where there are gaps.
  • 🔗 Strategic fit on each project: The goal card on the project overview shows a new line Strategy: with links to the objectives or initiatives the project serves. The project leader, deputy and sponsor edit them with the pencil icon - up to three links, one of them primary.
  • 🧭 Coverage & gap analysis: See at a glance which objectives no project serves yet (unfunded goals) and which projects are not linked to any objective.
  • 📊 Independent objective owner assessments: Objective owners set their own assessment (on track, at risk, off track, not started) with an optional note, independently of the projects.
  • 💰 Accurate rollups: Total and current-year budget roll up to each objective, with no double counting when a project serves more than one objective (only the primary link counts).
  • 📦 Non-destructive retiring: A strategy, objective or initiative can be retired without losing the links on the projects. It stays visible on projects that already linked to it, marked as (retired).

For Site Owners

  • • Turn the module on or off in Configuration > Settings under Modules. It is off by default so your current setup does not change until you are ready.
  • • When you turn it on, the app automatically creates three lists in your site (Strategies, Strategic Objectives, Strategic Initiatives) and adds the Strategy column to your project list.
  • • Assign owners to objectives: Any user with site access can be an objective owner.
v1.2.0 Bilingual & UX
Production Build (SPFx 1.2.0.0)

Package Version 1.2.0.0

The app can now be used in English and German out of the box, with regional formatting and streamlined portfolio navigation.

What's New

  • 🌐 Language switcher: Click EN / DE in the top bar to switch between English and German. The choice is saved on your device. Additional language expansions will be introduced based on customer demand.
  • 🇩🇪 German everywhere: All screens, forms, tabs, buttons, messages, email templates, tooltips and help texts are fully translated.
  • 🚦 German status and RAG values: Project status, health and RAG values automatically translate when German is selected, while staying fully compatible with your existing data.
  • 📅 Regional dates and numbers: Dates (e.g. 27.09.2026) and numbers (e.g. 1'234 or 1 234) automatically follow your language and regional settings.
  • 📐 Milestones timeline spacing: The spacing between dense milestones on the project timeline has been widened so labels no longer overlap.
  • 🖥️ Status report editor: The editor now opens across the full screen width on wide monitors.

Improvements

  • • Standard phases: The default phase set has been refined to standard portfolio stages (Intake, Preparation, Execution, Handover, Close).
  • • Configuration menu: Administrative tools in the top bar are now grouped under Configuration (previously Settings).

Good to Know

  • • Export to Excel downloads column headers in the language you are currently using.
  • • Status report PDF exports keep the language of the user who generates the PDF.
  • • Project-specific texts that you write (project descriptions, comments, risk notes) remain in the language they were written in.

For Site Owners

  • • After updating the package, run Setup once from the Configuration menu. Existing project data is not modified.
  • • Choice lists (such as phase names and project types) remain in their original language. You can customize or translate them in Configuration > Choice Lists if needed.

Enterprise Maintenance & Update Guarantees

Designed specifically to comply with enterprise IT governance and zero-risk change controls.

How do updates reach my tenant?

PPM Compass 360 is packaged as a standard Microsoft SharePoint Framework (SPFx) package (.sppkg). You upload the updated package to your tenant App Catalog and click Deploy. Zero server access or PowerShell scripting required.

How does data migration work during updates?

All your data lives securely in your own SharePoint Online lists inside your tenant. Each release automatically migrates and adapts existing list items so they work with the new version. Your historical status reports, milestones, risks, and audit logs are fully preserved.

Can I roll back to an older version?

No. Backward rollbacks are not supported. When a new release introduces structural changes to SharePoint lists (such as new columns, views, or calculations), the list schema moves forward. For this reason, we strongly suggest testing each new package on a staging/sandbox site before rolling it into production.

How do we get notified of new updates?

Customers receive proactive release notifications with download links and changelogs. You control the deployment timing in your tenant App Catalog and can validate on a sandbox site at your own pace.
