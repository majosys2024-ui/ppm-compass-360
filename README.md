# PPM Compass 360 for Microsoft 365

> **In-Tenant Project Portfolio Management (PPM) & Strategic Portfolio Management (SPM) for Microsoft SharePoint Online.**

## Overview

**PPM Compass 360** is a native SharePoint Framework (SPFx) application engineered to deliver practical project portfolio governance and strategic alignment without the heavy administrative overhead of traditional enterprise PPM suites or the recurring per-seat licensing fees of Microsoft Power Apps.

### Key Capabilities

- **100% In-Tenant Data Sovereignty:** Zero data egress. All project data, risks, milestones, and financial records reside strictly within your Microsoft 365 / SharePoint Online tenant boundary.
- **Strategic Portfolio Management (SPM):** Connect projects directly to strategic objectives, evaluate objective progress independently, run coverage gap analysis to identify unfunded goals, and roll up budgets without double counting.
- **Automated Governance & Health Radar:** Algorithmic RAG health status derived from schedule, cost, risk, and scope indicators.
- **Milestone Trend Analysis (MTA):** Visual timelines, baseline comparison tracking, and uncertainty interval bands.
- **Native Least-Privilege Architecture:** Seamlessly integrates with Microsoft 365 permissions on dedicated Communication Sites. Site Members edit with automatic "Contribute Without Delete" protection, Site Visitors read, and Site Owners administer.
- **Bilingual Out-of-the-Box:** Instant English and German top-bar toggle with regional date, month, and number formatting.
- **Predictable Flat Licensing:** Flat annual per-site collection licensing with unlimited users, zero per-seat taxes, and zero Power Apps viewer license requirements.

## Live Website & GitHub Pages Deployment

This static site is pre-configured for **GitHub Pages** deployment with clean URLs:

1. In your GitHub repository, navigate to **Settings > Pages**.
2. Under **Build and deployment > Branch**, select `main` (or `master`) and directory `/(root)`.
3. Custom domain routing is handled via [`CNAME`](file:///Users/manu/Antigravity/Project1/CNAME) pointing to `ppmcompass.com`.
4. Enforce **HTTPS** in the repository settings.
